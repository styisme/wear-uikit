## 三、诚实声明

- **关于真机测试**：核心 UI 与交互已在真实设备上验证，但受限于设备数量，部分冷门 API（表冠阻尼、特定 ROM 的圆屏判断）的边缘场景尚未完全覆盖。
- **关于云端编译**：CI 通过仅代表语法与依赖正确，不代表所有功能在特定设备上绝对可用。
- **关于 AI 生成**：本库属于 AI 辅助驱动开发，抽取过程中的正则补丁与批量替换曾导致多次编译错误，最终依赖 CI 日志与人肉排查修复。
- **关于反射**：`UikitColor` 的 `system_accent1_*` 反射在非标准 ROM 上可能失效，已做 fallback。

## 五、我们承认这不完美

形式化的 PR 流程、逐行代码审阅、本地静态分析，在本仓库**可能全部缺位**。

我们用「**披露 + CI 门禁 + API 降级**」承担了**实质责任**，而非假装做到了所有**形式责任**。

这是约束下的选择，不是对标准的否定。
