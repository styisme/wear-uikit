# Contributing Guidelines

[简体中文](CONTRIBUTING.md) | **English**

## ⚠️ Build Environment Constraints
- **Gradle**: `5.6.4`
- **AGP**: `3.6.3`
- **JDK**: `8`

## Local Development
```bash
git clone https://github.com/styisme/wear-uikit.git
cd wear-uikit
gradle :uikit:assembleRelease :app:assembleDebug
```
